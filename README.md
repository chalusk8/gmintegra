# GMIntegra

Demo del panel admin SaaS para integraciones logísticas (React + Vite + Tailwind).

Datos y login son **mock** — no hay backend real.

## Demo login

| Usuario     | Contraseña  |
| ----------- | ----------- |
| `admin`     | `Admin2026!` |
| `ops.admin` | `Ops2026!`   |

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir [http://localhost:5173/](http://localhost:5173/).

## Build

```bash
npm run build
npm run preview
```

## Stack

- React 19 + Vite 8
- Tailwind CSS 4
- React Router 7
- Framer Motion + Lucide
